# Globe geography

`globe-land.json` contains an evenly spaced land point cloud derived from Natural Earth’s public-domain 1:110m land polygons. It contains geographic coordinates only, with no visitor data.

- Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson
- Terms: https://www.naturalearthdata.com/about/terms-of-use/
- Generator: `node scripts/globe-land.mjs path/to/ne_110m_land.geojson`
